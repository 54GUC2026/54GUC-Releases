# 5G / 4G Ultimate Controller (54GUC)

54GUC is a Windows app for monitoring and controlling supported LTE and 5G routers.

[Download the Windows beta](https://github.com/54GUC2026/54GUC-Releases/releases)
and [visit the website](https://54guc2026.54guc2026.workers.dev/) for screenshots,
licence generation and getting-started instructions. The app and router licences
are currently available at no charge.

1. Download the Windows ZIP from a release and extract it to a writable folder.
2. Connect your PC to the router network, then run **54GUC.exe** and select the exact supported router model and firmware.
3. Generate a router licence on the website and enter the complete code in the app.

Available readings and controls depend on the exact model and firmware. Start
with Brain off if you want to observe the connection before enabling automation.
Read the [use terms](https://54guc2026.54guc2026.workers.dev/legal#terms).
Third-party software notices and library-replacement rights are included with the
Windows package and described on the website.

This repository contains release downloads and these notes; application source
is private. GitHub's automatic Source code archives contain repository notes,
not the Windows app. Choose the **54GUC_Windows_portable_...zip** release asset.

Router bundles are optional and private. Do not add bundles, full History,
settings, credentials or personal information to this public repository. Use
the website's [bundle-sharing page](https://54guc2026.54guc2026.workers.dev/support).
Sharing does not include a commitment to reply, provide support or release updates.
